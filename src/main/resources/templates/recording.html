How It Works
  1. Paste raw HTTP request/response JSON
  2. Sanitize -- PCI/PII fields (card numbers, SSNs, tokens) are automatically masked
  3. Generate -- A stub definition is created from the sanitized traffic
  4. Decide -- based on confidence score and whether the path is payment/fraud/compliance:
    • AUTO_PUBLISHED confidence ≥ 90% and not a payment/fraud/compliance path — stub goes live immediately.
    • PENDING_REVIEW confidence is 70–89%, or the path contains "payment"/"fraud"/"compliance" (those ALWAYS require a human, even at 100% confidence — a hard guardrail, never auto-published).
    • REJECTED confidence is below 70% and it isn't a critical path — too much unmasked/unclassified risk to generate a stub at all.
