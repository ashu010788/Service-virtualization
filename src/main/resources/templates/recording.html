How It Works
  1. Paste raw HTTP request/response JSON
  2. Sanitize -- PCI/PII fields (card numbers, SSNs, tokens) are automatically masked
  3. Generate -- A stub definition is created from the sanitized traffic
  4. Confidence -- High-confidence stubs (>=90%) auto-publish; lower ones go to review
